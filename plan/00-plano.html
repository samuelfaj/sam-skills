Plano

Claude advisor (max) + sam-plan: improve sam-task gap detection; use graph engineering only if it helps; save freeze to ./plan

Goal

Make sam-task catch more structural and ledger gaps automatically (fail-closed) via deterministic validators and contracts, using a minimal ledger-graph approach—not a graph-runtime rebrand—and ship an executable phased plan under ./plan.

Thesis

Phased implementation P0→P4: (P0) sam-task schema v3 + validate_child_artifacts re-running plan/refine validators from durable paths; (P1) plan gap engine under READY only (non-empty criteria, AC↔step↔proof, step reachability, depends_on acyclic, UNKNOWN probes, ASSUMPTION acceptance hygiene, hedge-vs-FACT); (P2) refine CLOSED require_pass + UNKNOWN probes; closure per-finding correction tracking; (P3) contract-only adversarial ledger pass in closure-loop; (P4) document optional Graphify impact evidence in plan evidence-policy. No shared gap_engine import; no rebrand; duplicate tiny helpers only if needed under standalone install rules.

  • Rebrand/rewrite sam-task as graph engineering runtime with task-graph.json: Second serialization drifts from reports; zero extra gap detection once ID edges exist; high ceremony (advisor + simplicity rules).
  • Mandatory Graphify impact as READY gate: Host-dependent, non-deterministic availability; incentives to fabricate consultation; improves plan completeness not ledger integrity.
  • Shared cross-skill gap_engine.py library: Forbidden by validate_skill_suite standalone install contract.
  • Parallel DAG of canonical phases: Breaks single-final-head freshness; no latency evidence; contracts are intentionally serial.
